# Travel-Dreams
A modern, responsive travel agency website built from scratch using raw HTML, CSS, and JavaScript. Designed for Indian travel businesses with a focus on family trips, pilgrimages, and personalized journeys.

“We don’t just book tickets. We curate memories.”

# Features

- Clean responsive layout (desktop + mobile)
- Custom testimonial slider (vanilla JS)
- Smooth loader animation
- Booking contact form UI
- SEO & AI-friendly structure
- Travel services showcase
- Profile-based testimonial navigation
- No frameworks. No bloat. Just performance.

# Website Sections

1. Hero with brand message
2. Services (Flights, Trains, Hotels, Visas)
3. About Travel Dreams
4. Testimonials slider
5. Blog/Latest Posts
6. Gallery

# Tech Stack

- HTML5
- CSS (Flexbox + responsive design)
- Vanilla JavaScript
- Font Awesome icons
